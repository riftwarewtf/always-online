Kettu Plugins

Paste a folder URL into Kettu → Settings → Plugins → +

Toolbox

Copy embed contents, expand text attachments inline with Discord's own arrow, copy IDs, links, code blocks, sticker and emoji URLs. Keeps deleted messages in the chat and the text from before an edit. Every feature has its own switch.

DevTools

Web-inspector style debugging panel: console capture, an eval REPL, a network log, a module explorer and a React DevTools bridge.
